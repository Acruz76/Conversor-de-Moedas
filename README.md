Um projeto simples e interativo para conversão de moedas em tempo real, utilizando **HTML**, **CSS** e **JavaScript**.  
As cotações são buscadas através da [AwesomeAPI](https://docs.awesomeapi.com.br/api-de-moedas).

---

## 🚀 Funcionalidades
- **[Seleção de moedas](ca://s?q=Seleção_de_moedas_no_Conversor)**: escolha entre diversas moedas como Real, Dólar, Euro, Libra, Iene, entre outras.
- **[Conversão automática](ca://s?q=Conversão_automática_de_moedas)**: insira o valor e veja o resultado convertido instantaneamente.
- **[Interface amigável](ca://s?q=Interface_do_Conversor_de_Moedas)**: design limpo e responsivo com destaque para bandeiras e símbolos monetários.
- **[Feedback visual](ca://s?q=Feedback_visual_no_Conversor)**: mensagens de carregamento e erro em caso de falha na busca da cotação.

---

## 🛠️ Tecnologias utilizadas
- **HTML5** para estruturação da página  
- **CSS3** para estilização e responsividade  
- **JavaScript (ES6+)** para lógica de conversão e integração com API  

---

## 📸 Demonstração
Ao abrir o projeto, você verá:
- Um **card centralizado** com campos para selecionar moeda de origem e destino.  
- Um campo para inserir o valor desejado.  
- Um botão **Converter** que retorna o resultado com bandeiras e valores formatados.
